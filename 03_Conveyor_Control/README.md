# Förderbandsteuerung

## Projektübersicht
SPS-basierte Steuerung eines Förderbands mit Sensorik, Schrittkettenlogik und automatischem Ablauf.

## Hauptfunktionen
- Start und Stopp des Förderbands
- Erkennung von Werkstücken über Sensoren
- Ablaufsteuerung über Schrittkette
- Verarbeitung von Einfahrts- und Sensorsignalen
- Automatische Zustandswechsel
- Rücksetzen der Steuerung bei STOP, NOT-AUS oder Betriebsartenwechsel
- Mehrfache Verwendung von Funktionsbausteinen

## Hardware / Software
- Siemens S7-300
- TIA Portal
- Digitale Ein- und Ausgänge
- Sensoren
- Funktionsbausteine und Datenbausteine

## Verwendete SPS-Kenntnisse
- KOP / FUP
- Schrittketten
- Flankenauswertung
- FB / FC / DB
- Mehrfachaufrufe von Bausteinen
- Zustandslogik
- Fehlersuche und Test

## Ergebnis
Die Förderbandsteuerung wurde erfolgreich programmiert, kompiliert und auf der Trainingshardware getestet.
