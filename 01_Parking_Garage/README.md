# Parkhaussteuerung

## Projektübersicht
SPS-basierte Steuerung eines Parkhauses mit drei Etagen.

## Hauptfunktionen
- Fahrzeugzählung pro Etage
- Maximale Kapazität: 20 Fahrzeuge pro Etage
- Erfassung von Ein- und Ausfahrt über Sensoren
- Anzeige von Etage 1, Etage 2, Etage 3 und Gesamtbelegung
- Automatischer Anzeigewechsel alle 2 Sekunden
- BCD-formatierte Ausgabe für die Anzeige

## Hardware / Software
- Siemens S7-300
- TIA Portal
- Digitale Sensoren
- Zählerlogik
- Ausgang über AW0

## Verwendete SPS-Kenntnisse
- KOP / FUP
- Zählerprogrammierung
- Flankenauswertung
- Datenverarbeitung
- SPS-Adressierung
- Test und Fehlersuche

## Ergebnis
Das Programm wurde erfolgreich kompiliert, in die SPS geladen und an der Trainingshardware getestet.
