# Ampelsteuerung

## Projektübersicht
SPS-basierte Steuerung einer Straßenkreuzung mit Hauptstraße, Nebenstraße und Fußgängerampeln.

## Hauptfunktionen
- Hauptstraße Grün: 10 Sekunden
- Nebenstraße Grün: 7 Sekunden
- Zwischenzeiten zwischen den Ampelphasen
- Fußgängeranforderung über Taster
- Steuerung mehrerer Fußgängerampeln
- Ablaufsteuerung über Schrittketten
- Sichere Umschaltung zwischen den einzelnen Zuständen

## Hardware / Software
- Siemens S7-300
- TIA Portal
- Digitale Ein- und Ausgänge
- Timer
- Schrittkettenlogik

## Verwendete SPS-Kenntnisse
- KOP / FUP
- Ablaufsteuerung
- Timer
- Flankenauswertung
- Digitale Ein- und Ausgangsverarbeitung
- Zustandslogik
- Test und Fehlersuche

## Ergebnis
Die Ampelsteuerung wurde erfolgreich programmiert, kompiliert und auf der Trainingshardware getestet.
